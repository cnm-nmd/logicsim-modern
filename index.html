选择你熟悉的写法

普通表达式(P ∧ Q) → R键盘写法：(P & Q) -> R
逆波兰表达式P Q . R >先写命题，再写运算符；用空格分隔。
运算普通写法逆波兰写法
逻辑非¬P / !P / NOT PP <
逻辑与P ∧ Q / P & QP Q .
逻辑或P ∨ Q / P | QP Q ,
逻辑推出P → Q / P -> QP Q >
逻辑等价P ↔ Q / P <-> QP Q =

运算优先级：非 → 与 → 或 → 推出 → 等价。推出按右结合计算，例如 P → Q → R 表示 P → (Q → R)。不确定时，使用括号。

每一种视角，都有用途

结构图展示运算结构，可点按节点添加名称与备注。决策图按命题的真假选择分支，使用原版兼容的图形数据。真值表遍历所有组合；点按一行可应用该组合。

把思路保存下来

项目文件包含表达式、命题取值和节点备注。支持载入原版 nodeArray / linkArray JSON，也可在 JSON 视图中修改后“文本转图”。任意导入图只展示结构，真值分析需要表达式。

0 / 1 和 false / true 表示常量。命题名称区分大小写。最多 10 个不同命题，可导出完整 CSV、SVG 和 PNG。
